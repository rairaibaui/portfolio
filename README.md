## 🚀 How to Edit

### Add Your Projects to ITC-C508

Open `index.html` and find the ITC-C508 section. Replace the placeholder text:

```html
<li>Project 1: [Add your prelim project]</li>
```

With your actual project information:

```html
<li><a href="project-link.html">Project Title</a> - Project description</li>
```

### Update Contact Information

Find the Contact section and update the links:

```html
<a href="mailto:your-email@example.com" class="contact-link">📧 Email</a>
```

### Customize Colors

Edit the color variables in `styles.css`:

```css
:root {
    --primary-color: #f5f5f5;
    --secondary-color: #2c2c2c;
    --accent-color: #7c8aa7;
    --light-gray: #e8e8e8;
    --white: #ffffff;
}
```

## 🌐 Deploy to GitHub Pages

1. Go to your repository settings
2. Scroll to "Pages" section
3. Select `main` branch as source
4. Click Save
5. Your site will be live at: `https://rairaibaui.github.io/portfolio/`
